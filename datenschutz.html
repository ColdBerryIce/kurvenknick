für die Anwendung „Kurvenknick Upload“ und diese Webseite · Stand: 12. November 2026

1. Worum es geht

„Kurvenknick Upload“ ist ein privates Programm, das auf dem Computer des Betreibers des YouTube-Kanals Kurvenknick läuft. Es hat genau einen Zweck: eigene, fertige Videos auf den eigenen Kanal Kurvenknick hochzuladen und zu prüfen, ob die Verbindung zu diesem Kanal besteht. Es ist kein öffentlicher Dienst. Nur der Kanalbetreiber meldet sich damit an.

2. Welche Google-Daten die Anwendung nutzt

Die Anwendung verwendet die YouTube Data API mit zwei Berechtigungen:

  • Videos hochladen (youtube.upload): um Videos auf den eigenen Kanal hochzuladen.
  • YouTube-Konto ansehen (youtube.readonly): um Name und Handle des eigenen Kanals zu lesen und so zu prüfen, dass auf den richtigen Kanal hochgeladen wird.

Die Anwendung liest keine E-Mails, Kontakte, Dateien oder Daten anderer Personen.

3. Speicherung

Die Anmeldung bei Google (Zugangs-Token) wird nur lokal auf dem Computer des Kanalbetreibers gespeichert. Es gibt keinen Server, keine Datenbank und keine Cloud-Kopie dieser Daten. Die Anmeldung kann jederzeit unter myaccount.google.com/permissions widerrufen werden; danach kann die Anwendung nicht mehr auf das Konto zugreifen.

4. Weitergabe

Daten aus Google-Konten werden nicht verkauft, nicht an Dritte weitergegeben und nicht für Werbung oder zum Trainieren von KI-Modellen verwendet. Die Nutzung von Daten, die über Google-APIs empfangen werden, hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Für hochgeladene Videos gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.

5. Diese Webseite

Diese Seite setzt keine Cookies, hat keine Analyse- oder Werbewerkzeuge und keine Formulare. Sie wird über GitHub Pages bereitgestellt (GitHub Inc., USA). GitHub kann beim Aufruf technisch notwendige Daten wie die IP-Adresse verarbeiten, um die Seite auszuliefern und vor Angriffen zu schützen. Näheres in der Datenschutzerklärung von GitHub.
